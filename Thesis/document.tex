    \begin{abstract}
        
        本文针对微网与外部电网的电力调控问题，综合考虑购电和储能两部分，建立了由\textbf{混合整数线性规划}、\textbf{时间序列滚动预测}、\textbf{分位数风险修正}和\textbf{动态电价预测}等算法组成的购电与储能调度模型，为微网在不同信息条件和电价机制下制定经济、可靠的购电策略。\par
        
        \indent \textbf{针对问题一}，我们以购电量、充放电量、储电量和充放电状态为决策变量，以全天购电费用最小为目标，建立混合整数线性规划（MILP）模型。通过使用HiGHS求解器，我们求得最优计划：\textbf{全天购电量约为59482.70 kWh，购电费约为35126.95元，全天充电量和放电量分别约为20740.67 kWh和16799.94 kWh，储能损耗约为3940.73 kWh}。\par
        
        \indent \textbf{针对问题二}，在负载和光伏均存在不确定性的条件下，我们建立了历史数据驱动的日前购电模型。负载预测采用31天\textbf{滚动岭回归}，光伏预测则采用扩展窗口岭回归。在计算计划量时，我们为避免仅按点预测安排购电，采用风险裕度对净负荷进行风险修正，再通过每日储能MILP确定计划购电量、充放电量和富余量。最终\textbf{全年计划购电量约为22046434.84 kWh，紧急购电量约为126347.96 kWh，总费用约为14224462.52元}。结果表明，风险裕度分位数修正能在购电成本与缺电风险之间取得较好的平衡。\par
        
        \indent \textbf{针对问题三}，我们建立了多阶段滚动优化模型，其中负载继续采用问题二的滚动岭回归模型预测，光伏则只采用附件3的整点预报数据。为提高10分钟粒度预报精度，我们通过线性插值得到每10分钟的光伏发电量预报值。我们通过风险裕度搜索，得到误差分位数(用于量化风险裕度大小)均为0.60。\textbf{全年总费用约为13557776.15元，紧急购电量降至约47836.98 kWh}。后续的信息价值分析表明，现有四个预报时刻已覆盖主要可削减成本的信息，无需增加其它预报时点。\par
        
        \indent \textbf{针对问题四}，我们建立了基于动态电价预测的购电优化模型，利用过去7天日均电价构造逐时段滚动预测电价模型，分别重新求解问题2和3。计划购电和调整费用按预测电价计算，紧急购电费用按实际电价计算。电价预测模型的的逐时段$R^2$为0.8709，这说明了我们的模型能够较好的预测电价。经过计算，我们得出\textbf{问题4-2总费用约为14223905.42元，问题4-3总费用约为13536142.45元}，比4-2节省约687762.97元，说明多阶段调整确实能够有效降低实时电价环境下的紧急购电风险。\par
        
        \noindent \textbf{关键词}：微网调度；混合整数线性规划；滚动时间序列预测；分位数风险修正；多阶段调整；动态电价
        
    \end{abstract}

    \section{问题重述}
    
    微网是一种将光伏发电、小区负载和储能设备等分布式资源进行本地协调的小型发用电系统\cite{ZJMD202108005}。如何根据电价、小区负载、光伏发电功率和储能设备当前储电量，合理安排各时段的计划购电量与储能充放电量，是微网与外部电网协同调控的关键。\par
    
    由题意，储能设备最大容量为12000 kWh，最大充放电功率为5000 kW，2025年1月1日0:00的初始储电量为6000 kWh。为保证设备安全运行，后续过程中，储能设备的储电量必须始终保持在1200-10800 kWh之间，充放电效率均为90\%。\par
    
    根据附件提供的数据，本题需要依次解决以下四个问题：
    
    \begin{enumerate}
        \item [(1)] 在每天的电价和小区负载相同的前提下，每天0:00制定当天的计划购电策略，即当天每个 10 分钟时段的购电量，并给出全天购电量和购电费，以及六个四小时区间储能设备的充放电量和起止时刻储电量。
        
        \item [(2)] 每天的电价相同，但小区负载和光伏发电功率随时间变化，紧急情况下需要高价购电，利用实际小区负载与光伏发电功率历史数据，在每天0:00预测当天负载和光伏发电量，结合实际电价，制定当天的计划购电策略，并给出指定日期的购电量、充放电量、储电量及紧急购电结果。
        
        \item [(3)] 系统根据0点之前的历史数据和每个时间节点的未来光伏发电功率预报调整购电策略。若计划购电量与调整后的购电量不同，则要求支付相应的调整费用。
        需要建立包含计划购电费用、紧急购电费用和调整费用的优化模型，并分析是否需要引入其他时刻的预报。
        
        \item [(4)] 在外网电价随实际交易时刻波动的情况下，我们需要利用动态电价数据预测当天电价，重新建立微网购电模型，并依据已知历史数据分别重新求解问题2和问题3。
    \end{enumerate}
    
    \section{问题分析}
    
    本文要求建立模型来研究微网与外部电网之间的电力调控策略。
    核心任务是在储能设备运行约束下，根据电价、小区负载、光伏发电功率和当前储电量，
    合理确定计划购电量及储能充放电量，使微网既能满足小区负载需求，
    又能尽可能降低购电费用\cite{ZGDC201401001}。本文按照“确定性优化—时间序列预测—场景优化—多阶段调整”的思路展开\cite{DLXT201012005}。
    图~\ref{fig:power_allocation_relationship}清晰地展示了整个系统电力资源的流向与分布，
    总体上由外网和光伏发电来提供能量，供给小区负载并把多余的电能存储在储能设备中\cite{DLXT200820000}。\par

    \subsection{问题一的分析}
    
    问题一是电价、小区负载和光伏发电预测功率均已知的确定性日前调度问题。其中充放电时间窗口为10分钟，相对较短，在同一时段内充放电明显会提升问题复杂度。为简化问题，我们采用离散决策，通过设置决策变量$z_{d,t}$来决定某一时段是否充放电。我们将问题一的求解过程划分为以下几个步骤：
    
    \begin{enumerate}[label=(\arabic*),leftmargin=2.8em]
        \item 将一天划分为144个10分钟时段，把已知的各时段负载功率和光伏发电功率换算为对应的负载电量和光伏发电量。
        
        \item 设置购电量、充电量、放电量、时段末储电量和充放电状态五个决策变量，以全天购电费用最小为目标，建立混合整数线性规划模型(MILP)。
        
        \item 依次引入逐时供需平衡、储电量递推、储电量上下限、最大充放电功率、充放电互斥以及日初日末储电量相等等约束，保证调度计划满足负载需求和储能设备安全运行的条件。
        
        \item 利用HiGHS求解器求得MILP最优解，并通过独立计算供需残差、储电量递推残差和功率约束残差检验所得计划的可执行性。
    \end{enumerate}
    
    \subsection{问题二的分析}
    
    问题二中每天相同时段的电价不变，但小区负载和光伏发电功率逐日、逐时段变化。我们通过历史数据建立小区负载和光伏发电量的时间序列预测模型。预测数据用于指导优化0:00的计划购电策略，在实际运行中根据情况紧急购电，进而计算最后的总费用。具体分为以下几个步骤：
    
    \begin{enumerate}[label=(\arabic*),leftmargin=2.8em]
        \item 利用2025年1月数据进行模型参数选择，并计算2025年2月1日0:00的初始储电量。针对小区负载，使用前1、2、3、7日的滞后值、前3日和7日的同时刻均值、最近两个相同星期数日期的均值，同时考虑星期周期、年内周期和日内周期特征，建立31天滚动岭回归预测模型。
        
        \item 针对光伏发电，引入前1、2、3、7、14日的滞后值，前3日、7日和14日的同时刻均值，同时考虑由太阳赤纬描述的年内季节特征和日内周期特征，建立扩展窗口岭回归预测模型；随后将岭回归结果与最近7日同时刻均值进行加权融合，并对结果进行非负截断。
        
        \item 根据负载和光伏预测计算净负荷(同一时段小区负载与光伏发电量之差)，并利用最近60天同一时段的滚动预测误差确定具体的风险裕度系数和相应的裕度值。将该裕度值与预测净负荷相加，得到计划净负荷。由于实际缺口需要按5倍电价紧急购电，我们需要在计划购电成本和缺电风险之间建立量化平衡，避免仅按预测均值安排购电。
        
        \item 以计划购电费最小为目标，综合考虑多个约束条件，在当天0:00求解储能调度MILP模型。在微网实际运行阶段，使用当天的真实负载和光伏逐时段发电功率计算紧急购电量。
        
        \item 按照上述流程，滚动求解2025年2月1日至2025年12月31日的计划购电量、实际充放电量、紧急购电时段和总费用。
    \end{enumerate}
    
    \subsection{问题三的分析}
    
    问题三在第二问的基础上增加了日内光伏预报更新和购电调整机制。每天有四个预报发布的时刻：0:00、6:00、12:00和18:00。通过预报数据，在相应时刻调整供电量。为刻画信息更新、预报订正和费用结算过程，我们将问题三分为以下几个步骤：
    
    \begin{enumerate}[label=(\arabic*),leftmargin=2.8em]
        \item 首先对预报数据进行历史回归，明确光伏发电量的变化规律。计算目标日之前若干天光伏发电功率的实际小时均值，建立一元线性回归，插值求解光伏发电量每10分钟的预测值。
        \item 本文采用\textbf{分段裕度系数}控制当天计划购电的保守程度。对每天的前36个时段和后108个时段，我们使用最近60天预测数据的误差分别进行修正，同时遍历裕度系数，得到夜间和白天的最优分位数作为最终裕度系数。
        
        \item 使用计划购电与储能MILP模型，求解全天计划购电量、充放电量、富余量和储电量。在6:00、12:00和18:00根据最新光伏预报、已发生实际数据和当前储电量，调整尚未执行的当天后续时段。在实际运行时优先消耗储能设备中的富余电量，剩余差值按5倍电价紧急购电。
    \end{enumerate}
    
    \subsection{问题四的分析}
    
    问题四进一步考虑外网电价随交易时刻的波动，分别重新计算问题2和问题3。此时电价不再是已知的固定曲线，我们需要依据历史电价和日内规律进行预测和调整。实际运行中的紧急购电费用按照实际电价结算。将问题四分为以下步骤：
    
    \begin{enumerate}[label=(\arabic*),leftmargin=2.8em]
        \item 分析并总结实际电价的变化趋势和规律，设计Rolling滚动均值预测模型，在0：00预测当天各个时段的电价。
        
        \item 重新计算问题2时，使用预测电价来建立储能MILP模型；计算问题3时，使用预测电价来建立多阶段调整-储能优化模型，求解总费用、计划购电量、充放电量和紧急购电量。实际运行中，紧急购电费使用实际电价计算。
    \end{enumerate}
    
    \section{模型假设}
    
    \begin{enumerate}
        \item 假设附件中的电价、小区负载和光伏发电功率数据真实可靠。各时段的功率数据视为该10分钟区间内的平均功率。
        
        \item 题目所给时间标签表示对应时段的结束时刻，例如附件中的0:10表示0:00--0:10时段，0:00+1表示当天24:00。
        
        \item 假设外网能够完全满足微网的计划购电和紧急购电需求，不考虑外网故障、限电或供电中断。
        \item 模型不考虑储能设备的自放电以及电池老化、循环寿命和折旧费用。
        
        \item 同一10分钟时段内储能设备最多只能充电、放电或闲置，不能同时进行充电和放电；每个时段内的平均充放电功率不超过设备功率上限。
        
        \item 问题一中光伏预测电量全部用于供应小区负载或为储能设备充电，不向外网售电，也不允许浪费光伏设备的发电量；问题二至问题四中未被利用的富余电量不能获得退款或售电收益。
        
        \item 紧急购电只在储能调节后仍然存在供电缺口时发生，且不考虑额外手续费、容量费用或违约以外的其他惩罚费用。
        
        \item 模型不考虑通信延迟、设备故障、人工操作误差以及题目未给出的其他随机因素。
    \end{enumerate}

    \section{模型建立与求解}
    
    \subsection{问题一：确定性条件下的计划购电与储能优化模型}
    
    \subsubsection{建模思路与时间离散化}
    
    电价、小区负载和光伏预测均为已知量，目标是在满足小区负载需求和储能设备安全约束的前提下，确定全天各时段的购电量以及储能充放电量，使全天购电费用最小。由于储能设备的当前动作会影响后续时段的可用容量，且同一时段不能同时充电和放电，该问题同时包含连续变量和0-1变量，因此本文将其建模为混合整数线性规划问题\cite{1664974}。\par
    
    我们将一天等分为$T=144$个时段，来对齐附件表格，每个时段{$\Delta t = 10 min$}。第$t$个时段记为$[(t-1)\Delta t,t\Delta t]$。设第$t$时段的小区负载平均功率为$L_t$，光伏预测平均功率为$\widehat P_t$，则小区负载电量和光伏预测电量分别为
    
    \begin{equation}
        \ell_t=L_t\Delta t,\qquad v_t=\widehat P_t\Delta t
    \end{equation}
    
    \subsubsection{决策变量与目标函数}
    
    设第$t$时段从外网购入的计划电量为$g_t$，微网送入电池的外部电量为$c_t$，电池向微网交付的外部电量为$d_t$，时段结束时电池的内部储电量为$S_t$。我们引入0--1变量$z_t$表示充放电状态：
    
    \begin{equation}
        z_t=
        \begin{cases}
            1, & \text{第$t$时段充电},\\
            0, & \text{第$t$时段放电或闲置}
        \end{cases}
    \end{equation}
    
    由于购电量$g_t$的单位为kWh，目标函数可直接写为各时段购电量与购电价格乘积之和：
    
    \begin{equation}
        \min F=\sum_{t=1}^{T}p_tg_t
    \end{equation}
    
    \subsubsection{供需平衡与储能约束(模型约束条件)}
    
    在模型假设下，每个时段获得的电量等于负载消耗与电池充电量之和，因此逐时供需平衡约束为
    
    \begin{equation}
        g_t+v_t+d_t=\ell_t+c_t,\qquad t=1,2,\ldots,T
    \end{equation}
    
    整理可得
    
    \begin{equation}
        g_t=\ell_t-v_t+c_t-d_t
    \end{equation}
    
    由该式可以看出，电池充电会增加购电需求，电池放电会减少购电需求，而光伏发电则会直接抵扣部分负载电量。\par
    
    采用电池内部电量计算储电量，充放电效率分别为$\eta_c$和$\eta_d$，所得储电量递推关系为
    
    \begin{equation}
        S_t=S_{t-1}+\eta_cc_t-\frac{d_t}{\eta_d},
        \qquad t=1,2,\ldots,T    
    \end{equation}
    
    其中$\eta_c=\eta_d=0.9$。电池运行过程中必须满足储电量上下限\cite{7779156}：
    
    \begin{equation}
        S_{\min}\leq S_t\leq S_{\max},
        \qquad S_{\min}=1200,\quad S_{\max}=10800
    \end{equation}
    
    同时，题目要求日初和日末储电量相同:
    
    \begin{equation}
        S_0=S_T=6000
    \end{equation}\par
    
    设电池的最大充电功率和最大放电功率分别为$P_c^{\max}=P_d^{\max}=5000$ kW，则每个时段的最大外部充放电量为
    
    \begin{equation}
        C_{\max}=P_c^{\max}\Delta t=\frac{2500}{3}\ \mathrm{kWh},\qquad
        D_{\max}=P_d^{\max}\Delta t=\frac{2500}{3}\ \mathrm{kWh}.
    \end{equation}
    
    利用二元变量$z_t$建立充放电功率约束和互斥约束：
    
    \begin{equation}
        0\leq c_t\leq C_{\max}z_t,
    \end{equation}
    
    \begin{equation}
        0\leq d_t\leq D_{\max}(1-z_t),
    \end{equation}
    
    \begin{center}
        \(g_t\geq0,\qquad z_t\in\{0,1\}\) 
    \end{center}
    
    当$z_t=1$时，$d_t=0$，电池只能充电；当$z_t=0$时，$c_t=0$，电池只能放电或闲置，从而避免同一时段出现同时充放电的现象。\par
    
    
    综合以上目标函数和约束条件，我们将问题一建立的的完整模型表述如下
    
    \begin{equation}
        \begin{aligned}
            \min\quad & F=\sum_{t=1}^{T}p_tg_t\\
            \text{s.t.}\quad
            & g_t+v_t+d_t=\ell_t+c_t, && t=1,\ldots,T,\\
            & S_t=S_{t-1}+\eta_cc_t-\frac{d_t}{\eta_d}, && t=1,\ldots,T,\\
            & S_{\min}\leq S_t\leq S_{\max}, && t=0,\ldots,T,\\
            & 0\leq c_t\leq C_{\max}z_t, && t=1,\ldots,T,\\
            & 0\leq d_t\leq D_{\max}(1-z_t), && t=1,\ldots,T,\\
            & g_t\geq0,\quad z_t\in\{0,1\}, && t=1,\ldots,T,\\
            & S_0=S_T=6000
        \end{aligned}
    \end{equation}
    
    模型中的目标函数和所有约束均为线性形式，其中$z_t$为整数变量，其余变量为连续变量，因此该模型属于混合整数线性规划模型\cite{Parisio2014AMP}。
    
    \subsubsection{基于HiGHS求解器的模型求解}
    
    我们将已知的电价、小区负载和光伏预测功率代入模型后，使用SciPy提供的\texttt{optimize.milp}接口调用HiGHS求解器直接进行求解。\par
    
    求解器在约0.033秒内收敛，最优性相对间隙为0，即模型在当前数值容差下达到最优。需要强调的是，\textbf{求解器报告成功只表示数值算法在当前容差内找到了满足约束的最优解，并不能代替物理可行性证明}。因此，本文在得到求解器返回的$g,c,d,S,z$后，不直接以求解器状态作为最终判据，而是重新按照物理关系计算残差。\par
    
    首先计算逐时供需平衡的最大残差：
    
    \begin{equation}
        R_{\mathrm{balance}}
        =\max_t
        \left|
        g_t+v_t+d_t-\ell_t-c_t
        \right|
    \end{equation}
    
    其次计算储能状态递推的最大残差：
    
    \begin{equation}
        R_{\mathrm{storage}}
        =\max_t
        \left|
        \Delta S_t-\eta_cc_t+\frac{d_t}{\eta_d}
        \right|,
        \qquad
        \Delta S_t=S_t-S_{t-1}
    \end{equation}
    
    此外，我们还需要独立检查储电量上下限、日初日末储电量、购电量和充放电量非负、充放电功率上限、状态变量整数性、同时充放电量以及全天储能循环关系。设允许容差
    
    \begin{equation}
        \varepsilon=10^{-5}\ \mathrm{kWh}
    \end{equation}
    
    只有当上述全部残差均不超过$\varepsilon$时，才判定该解通过物理可行性校验；若任一残差超过容差，则拒绝该解，而非仅根据HiGHS状态接受求解结果。\par
    
    为了进一步检验全天电能总体守恒情况，定义全天购电量、负载电量、光伏电量和充电量：
    
    \begin{equation}
        G=\sum_{t=1}^{T}g_t,\qquad
        E_L=\sum_{t=1}^{T}\ell_t,\qquad
        E_{PV}=\sum_{t=1}^{T}v_t,\qquad
        C=\sum_{t=1}^{T}c_t
    \end{equation}
    
    由于日初和日末储电量相同，全天充放电满足
    
    \begin{equation}
        \sum_{t=1}^{T}d_t
        =\eta_c\eta_d\sum_{t=1}^{T}c_t
        =\eta_c\eta_dC
    \end{equation}
    
    因此全天能量守恒残差为
    
    \begin{equation}
        R_{\mathrm{day}}
        =
        \left|
        G-E_L+E_{PV}
        -(1-\eta_c\eta_d)C
        \right|
    \end{equation}

    \subsection{问题二：滚动预测与风险修正下的购电和储能优化模型}
    
    \subsubsection{建模思路与总体框架}
    
    问题二每天的电价规律相同，但负载和光伏实际功率随时间变化。0:00制定计划时只能利用此前已经掌握的历史信息，因此可以将预测公式分解为滚动预测和风险修正两个部分。设第$k$天包含$T=144$个时段，负载和光伏预测功率分别为$\widehat L_{k,t}$和$\widehat{PV}_{k,t}$，对应的预测净负荷电量为
    
    \begin{equation}
        \widehat N_{k,t}
        =\left(\widehat L_{k,t}-\widehat{PV}_{k,t}\right)\Delta t
    \end{equation}
    
    为避免仅按预测均值安排购电造成高额紧急购电费用，本文利用历史预测误差的80\%分位数对预测净负荷进行修正，并作为当日储能调度MILP的输入\cite{HONG2016914}。当天运行阶段再根据实际负载和光伏执行储能动作，并对电池放电后仍存在的缺口进行紧急购电。\par
    
    \subsubsection{滚动预测设置}
    
    所有预测均采用逐日滚动方式：预测第$k$天时只使用第$k$天以前的数据；当天结束后，再将该天实际值加入历史序列并预测下一天。\par
    
    2025年1月作为模型预运行期，用于模型参数选择、历史预测残差估计以及储能设备状态初始化，使储能系统在进入正式计算期前达到合理的运行状态。因此根据问题1得出的购电策略购电，算出2月1日0:00时刻储能设备的初始电量。正式预测和费用统计区间为2025年2月1日至12月31日。模型输出逐日负载和光伏预测值，并整理为\texttt{pred.xlsx}，作为第二问购电与储能调度的输入。\par
    
    \subsubsection{负载与光伏时间序列预测模型}
    
    住宅小区负载具有明显的日内周期和周周期。以天为时间尺度时，在工作日时8:00-18:00用电量显著提高，而非工作日此时段增长幅度较小；对于光伏发电，大致的发电区间在6:00-18:00,根据年际太阳升起降落的时间前后摆动，且总体上呈现出先上升后下降的抛物线模型。以年为时间尺度时，以12:00为例，全年的小区负载周末为波谷，工作日为波峰，一个月大致有四个波峰，呈现出比较明显的波动特征；对于光伏发电则在3-5月和8-11月处在高位，而其余时段发电量较少，周内没有呈现明显的规律特征。\par
    
    对目标日第$t$个时段，负载模型使用前1、2、3、7日的滞后值、前3日和7日的同时刻均值、最近两个相同星期几的均值，以及星期周期、年内周期和日内周期特征。设目标时段的特征向量为$X^L_{k,t}$，则负载采用最近31天窗口的岭回归预测：
    
    \begin{equation}
        \widehat L_{k,t}=X^L_{k,t}\beta_L,
    \end{equation}
    
    \begin{equation}
        \widehat\beta_L
        =\arg\min_{\beta}
        \left\|
        Y_L-X^L\beta
        \right\|_2^2
        +\lambda_L\|\beta\|_2^2
    \end{equation}
    
    其中，岭参数$\lambda_L$在$\{0.1,1,10,100\}$中利用1月数据选择，以平均绝对误差最小为目标，当前数据下取$\lambda_L=100$\cite{Hoerl01021970}。\par
    
    光伏发电除受近期天气影响外，还具有明显的太阳高度角季节规律\cite{ANTONANZAS201678}。定义第$k$天的太阳赤纬为
    
    \begin{equation}
        \delta_k
        =23.44^\circ
        \sin\left[
        \frac{2\pi(D_k-81)}{365}
        \right]
    \end{equation}
    
    其中$D_k$为年内序号。光伏特征包括前1、2、3、7、14日的滞后值，前3日、7日和14日的同时刻均值，以及$\sin(\delta_k)$、$\cos(\delta_k)$和日内周期项。采用扩展窗口岭回归得到$\widehat{PV}^{\,ridge}_{k,t}$，并与最近7日同时刻均值
    
    \begin{equation}
        \widehat{PV}^{\,7}_{k,t}
        =\frac{1}{7}\sum_{j=1}^{7}PV_{k-j,t}
    \end{equation}
    
    进行融合：
    
    \begin{equation}
        \widehat{PV}_{k,t}
        =\max\left\{
        0,\ 
        \alpha\widehat{PV}^{\,7}_{k,t}
        +(1-\alpha)\widehat{PV}^{\,ridge}_{k,t}
        \right\}
    \end{equation}
    
    利用1月白天时段数据选择参数，当前取岭参数1、融合权重$\alpha=0.4$。将滚动预测结果与附件2实际值进行比较，负载和光伏的$R^2$分别为0.9745和0.9899，说明模型能够较好刻画全年负载和光伏的变化趋势。
    
    \subsubsection{预测误差与80\%分位数风险修正}
    
    实际净负荷电量为
    
    \begin{equation}
        N_{k,t}
        =\left(L_{k,t}-PV_{k,t}\right)\Delta t
    \end{equation}
    
    预测误差为
    
    \begin{equation}
        \varepsilon_{k,t}
        =N_{k,t}-\widehat N_{k,t}
    \end{equation}
    
    当$\varepsilon_{k,t}>0$时，表示实际净负荷高于预测，容易产生紧急购电；当$\varepsilon_{k,t}<0$时，表示可能出现计划购电富余。由于紧急购电价格为正常电价的5倍，本文使用最近60天同一时段的历史预测误差，取80\%分位数作为风险裕量\cite{GNEITING2011197}：
    
    \begin{equation}
        q_{k,t}
        =Q_{0.8}
        \left\{
        \varepsilon_{k-1,t},
        \varepsilon_{k-2,t},
        \ldots,
        \varepsilon_{k-60,t}
        \right\}
    \end{equation}
    
    最终用于制定计划的净负荷为
    
    \begin{equation}
        N^{\mathrm{plan}}_{k,t}
        =\widehat N_{k,t}+q_{k,t}
    \end{equation}
    
    该修正会在预测误差偏正时提高计划购电量，在误差偏负时适当降低备购量，实现实时信息反馈调节。从而在计划购电成本和五倍紧急购电风险之间取得平衡。\par
    
    \subsubsection{实际运行与跨日滚动求解}
    
    计划购电曲线在0:00锁定后，当天按实际负载和光伏逐时段运行。定义电池动作前的供需差额为
    
    \begin{equation}
        a_{k,t}
        =g_{k,t}+PV_{k,t}\Delta t-L_{k,t}\Delta t
    \end{equation}
    
    当$a_{k,t}\geq0$时，计划电量和光伏已经满足负载，此时不进行紧急购电，富余电量优先充电：
    
    \begin{equation}
        c_{k,t}
        =\min\left\{
        a_{k,t},\ 
        C_{\max},\ 
        \frac{S_{\max}-S_{k,t-1}^{\mathrm{act}}}{\eta_c}
        \right\}
    \end{equation}
    
    未利用富余电量为$u_{k,t}=a_{k,t}-c_{k,t}$。当$a_{k,t}<0$时出现供电缺口，电池优先放电：
    
    \begin{equation}
        d_{k,t}
        =\min\left\{
        -a_{k,t},\ 
        D_{\max},\ 
        \eta_d\left(S_{k,t-1}^{\mathrm{act}}-S_{\min}\right)
        \right\}
    \end{equation}
    
    若放电后仍有缺口，则进行紧急购电：
    
    \begin{equation}
        e_{k,t}
        =\max\left\{0,\ -a_{k,t}-d_{k,t}\right\}
    \end{equation}
    
    实际储电量按
    
    \begin{equation}
        S_{k,t}^{\mathrm{act}}
        =S_{k,t-1}^{\mathrm{act}}
        +\eta_cc_{k,t}
        -\frac{d_{k,t}}{\eta_d}
    \end{equation}
    
    更新，并满足跨日连续约束
    
    \begin{equation}
        S_{k+1,0}^{\mathrm{act}}=S_{k,T}^{\mathrm{act}}
    \end{equation}
    
    2025年1月1日初始储电量为6000 kWh，经过1月热启动后，2月1日初始储电量达到10800 kWh。\par

    \subsection{问题三：光伏预报驱动的多阶段购电和储能优化模型}
    
    \subsubsection{多阶段决策与信息结构}
    
    在问题二的基础上，问题三引入了预测光伏发电功率的因素\cite{article}，并在一天中设置四个预报发布和决策时刻：
    
    \begin{equation}
        \mathcal E=\{0,6,12,18\}
    \end{equation}
    
    在0:00根据预测制定全天购电计划，在6:00、12:00和18:00结合新的预报和已知数据进行调整，计算出调整后的购电计划。时刻$\tau$的信息集记为$\mathcal F_{d,\tau}$，包含历史数据、当天已经观测到的实际值、当前时刻发布的光伏发电量预报，以及当前储电量和电价。所以问题三是在已有计划的基础上，加入多阶段滚动调整的过程。\par
    
    从决策结构来看，总购电费由计划购电费，调整购电费和紧急购电费三部分组成。因此问题三可分解为三个层次：第一是制定计划购电策略，第二是根据预测数据进行滚动调整，第三是结算实际运行产生的费用。\par
    
    在时刻$\tau$发布的未来第$h$小时光伏预测功率为$\widehat{PV}_{d,\tau,h}$，其对应的10分钟时段编号为
    
    \begin{equation}
        s_h=6(\tau+h-1),\qquad h=1,2,\ldots,24
    \end{equation}
    
    对于位于相邻两个整点节点之间的时段$t$，我们采用线性插值的手段获得光伏预测功率：
    
    \begin{equation}
        \widehat{PV}_{d,\tau,t}
        =\widehat{PV}_{d,\tau,h}
        +\frac{t-s_h}{6}
        \left[
        \widehat{PV}_{d,\tau,h+1}
        -\widehat{PV}_{d,\tau,h}
        \right]
    \end{equation}
    
    曲线两端水平外推，$t\leq s_1$和$t\geq s_{24}$时分别取首尾整点预报值。由此得到每个决策时刻可直接用于优化模型的光伏功率曲线。\par
    
    \subsubsection{计划购电策略的制定}
    
    在0:00，微网根据当天的负载预测和光伏预报，制定全天144个时间段的计划购电策略。计划购电模型以全天计划购电费用最小为目标：
    
    \begin{equation}
        \begin{aligned}
            \min\quad
            & \sum_{t=1}^{T}p_tg_{d,t}^{\mathrm{plan}}
        \end{aligned}
    \end{equation}
    
    约束条件大致可分为以下五类：\par
    
    第一，每个时段内充放电功率须保持平衡，购电量与放电量之和减去充电量与缺电量，应等于预测净负荷。
    
    \begin{equation}
        \begin{aligned}
            g_{d,t}^{\mathrm{plan}} + d_{d,t}^{\mathrm{plan}} - c_{d,t}^{\mathrm{plan}} - u_{d,t}^{\mathrm{plan}} = \widehat N_{d,t|0}
        \end{aligned}
    \end{equation}
    
    第二，储电设备需要满足储电量递推关系：
    
    \begin{equation}
        \begin{aligned}
            S_{d,t}^{\mathrm{plan}} = S_{d,t-1}^{\mathrm{plan}} + 0.9c_{d,t}^{\mathrm{plan}} - \frac{d_{d,t}^{\mathrm{plan}}}{0.9}
        \end{aligned}
    \end{equation}
    
    第三，储电设备的储电量必须在上下限之间：
    
    \begin{equation}
        \begin{aligned}
            1200 \leq S_{d,t}^{\mathrm{plan}} \leq 10800
        \end{aligned}		
    \end{equation}
    
    第四，储电设备的充放电功率必须在最大充放电功率范围内：
    
    \begin{equation}
        \begin{aligned}
            0 \leq c_{d,t}^{\mathrm{plan}} \leq \frac{2500}{3}z_{d,t}, \\
            0 \leq d_{d,t}^{\mathrm{plan}} \leq \frac{2500}{3}(1-z_{d,t})
        \end{aligned}
    \end{equation}
    
    第五，所有决策变量需要满足非负约束：
    
    \begin{equation}
        \begin{aligned}
            g_{d,t}^{\mathrm{plan}} \geq 0,\qquad u_{d,t}^{\mathrm{plan}} \geq 0,\qquad z_{d,t} \in \{0,1\}
        \end{aligned}
    \end{equation}
    
    0:00发布的光伏预报，经插值后记为$\widehat{PV}_{d,0,t}$，此时的预测净负荷电量为
    
    \begin{equation}
        \widehat N_{d,t|0}
        =\left(
        \widehat L_{d,t|0}
        -\widehat{PV}_{d,0,t}
        \right)\Delta t
    \end{equation}
    
    该模型是一个混合整数线性规划模型，可以用标准求解器进行求解，从而得到当天计划购电量$g_{d,t}^{\mathrm{plan}}$，充放电量以及储能轨迹。\par
    
    \subsubsection{滚动调整模型}
    
    对于任意调整时刻$\tau\in\{6,12,18\}$，微网获得新的光伏预报，同时也已经观察到当天部分时段的实际数据。\par
    
    此时，微网对剩余时段的购电-储能策略进行调整。更新后的预测净负荷为：
    
    \begin{equation}
        \widehat N_{d,t|\tau}
        =\left(
        \widehat L_{d,t|\tau}
        -\widehat{PV}_{d,\tau,t}
        \right)\Delta t,
        \qquad t\in\mathcal T_\tau
    \end{equation}
    
    剩余时段的策略仍需满足储能设备的约束条件：
    
    \begin{equation}
        g_{d,t|\tau}^{\mathrm{adj}}+d_{d,t|\tau}
        -c_{d,t|\tau}-u_{d,t|\tau}
        =\widehat N_{d,t|\tau},
    \end{equation}
    
    \begin{equation}
        S_{d,t|\tau}=S_{d,t-1|\tau}
        +0.9c_{d,t|\tau}
        -\frac{d_{d,t|\tau}}{0.9},
    \end{equation}
    
    \begin{equation}
        g_{d,t|\tau}^{\mathrm{adj}}
        =g_{d,t|\tau^-}^{\mathrm{adj}},
        \qquad t\leq k_\tau
    \end{equation}
    
    每个时段最终调整量相对原计划量的差额为
    
    \begin{equation}
        \Delta_{d,t}
        =g_{d,t}^{\mathrm{adj}}-g_{d,t}^{\mathrm{plan}}
    \end{equation}
    
    滚动调整模型的目标是最小化调整带来的额外费用，我们将调整量分解为调高量和调低量，定义为正偏差和负偏差：
    
    \begin{equation}
        \Delta_{d,t}^{+}
        =\max\left\{g_{d,t}^{\mathrm{adj}}-g_{d,t}^{\mathrm{plan}},0\right\},
    \end{equation}
    
    \begin{equation}
        \Delta_{d,t}^{-}
        =\max\left\{g_{d,t}^{\mathrm{plan}}-g_{d,t}^{\mathrm{adj}},0\right\}
    \end{equation}
    
    根据题目，正偏差电价为交易时刻电价的1.5倍；负偏差电价，即违约电价为交易时刻电价的50\%。因此，调整模型的目标函数为：
    
    \begin{equation}
        \begin{aligned}
            \min\quad
            & \sum_{t=t_{h}}^{T}(1.5p_{t}\Delta_{d,t}^{+}+0.5p_t\Delta_{d,t}^{-})
        \end{aligned}
    \end{equation}
    
    调整模型的约束与计划模型类似，但作用于剩余时段。储能递推、充放电互斥、储电量范围约束均保持一致。为保证储能运行的连续性，调整模型要求剩余时段结束时储电量不低于目标值：
    
    \begin{equation}
        \begin{aligned}
            S_{T} + s_{short} \geq S_{target}
        \end{aligned}
    \end{equation}
    
    调整模型同样是一个MILP，求解后得到调整后购电量，并用其覆盖计划购电量中对应剩余时段的部分。\par
    
    
    \subsubsection{实际运行与紧急购电}
    
    制定计划后，微网按实际小区负载和实际光伏发电功率运行。若计划购电量、光伏发电功率和储能设备放电量之和仍不足以满足负载，则产生紧急购电。定义电池做出实际应答前的供需差额为
    
    \begin{equation}
        a_{d,t} = g_{d,t}^{\mathrm{adj}} + PV_{d,t} \Delta t - L_{d,t}\Delta t
    \end{equation}
    
    当$a_{d,t} \geq 0$时，不需要放电和紧急购电，富余电量优先充电：
    
    \begin{equation}
        c_{d,t} = \min \left\{
        a_{d,t},\ 
        \frac{2500}{3},\ 
        \frac{10800 - S_{d, t - 1}^{\mathrm{act}}}{0.9}
        \right\},
    \end{equation}
    
    未利用富余电量为$u_{d,t} = a_{d,t} - c_{d,t}$。当$a_{d,t} < 0$时，电池优先放电：
    
    \begin{equation}
        d_{d,t} =\min \left\{
        -a_{d,t},\ 
        \frac{2500}{3},\ 
        0.9\left(S_{d, t - 1}^{\mathrm{act}} - 1200\right)
        \right\},
    \end{equation}
    
    若电池放电后仍有缺口，则紧急购电量为
    
    \begin{equation}
        e_{d,t} = \max \left\{
        0,\ 
        -a_{d,t}-d_{d,t}
        \right\}
    \end{equation}
    
    实际储电量按照
    
    \begin{equation}
        S_{d,t}^{\mathrm{act}} = S_{d,t-1}^{\mathrm{act}} + 0.9c_{d,t} - \frac{d_{d,t}}{0.9}
    \end{equation}
    
    更新，并满足跨日连续约束
    
    \begin{equation}
        S_{d + 1,0}^{\mathrm{act}} = S_{d,T}^{\mathrm{act}}
    \end{equation}
    
    计划购电费用、调整费用和紧急购电费用分别为
    
    \begin{equation}
        C_d^{\mathrm{plan}} = \sum_{t = 1}^{T}p_tg_{d,t}^{\mathrm{plan}},
    \end{equation}
    
    \begin{equation}
        C_d^{\mathrm{adj}} = \sum_{t = 1}^{T} \left[ 1.5p_t\Delta_{d,t}^{+} + 0.5p_t\Delta_{d,t}^{-} \right],
    \end{equation}
    
    \begin{equation}
        C_d^{\mathrm{em}} = \sum_{t = 1}^{T}5p_te_{d,t}
    \end{equation}
    
    因此，当天总费用为
    
    \begin{equation}
        C_d=C_d^{\mathrm{plan}}+C_d^{\mathrm{adj}}+C_d^{\mathrm{em}}
    \end{equation}
    
    每天0:00，以计划购电费用、调整购电费用和紧急购电费用的总和最小为目标；在6:00、12:00和18:00重新求解剩余时段的调整问题。每天按“0:00计划—6:00调整—12:00调整—18:00调整—实际运行”的顺序滚动执行，并将当天末储电量传递给下一天。\par

    \subsection{问题四：动态电价预测与购电成本优化模型}
    
    \subsubsection{Rolling电价预测模型}
    
    附件4给出第$d$天第$t$个时段的实际电价$p_{d,t}^{\mathrm{act}}$。根据144个时间段可以计算当日电费的日均价，然后采用过去7天日均价的平均值预测得到下一天的价格水平\cite{LAGO2021116983}。再根据附件1进行相同的计算，得到经验日均价。于是在附件1经验时段价格的基础上再加上近7天和经验日均价的差值得到预测电价，若预测电价低于0则将电价视为0。具体公式如下：
    
    \begin{equation}
        y_d=\frac{1}{144}\sum_{t=1}^{144}p_{d,t}^{\mathrm{act}}
    \end{equation}
    
    \begin{equation}
        \widehat y_d
        =\frac{1}{7}\sum_{k=1}^{7}y_{d-k}
    \end{equation}
    
    \begin{equation}
        \overline p
        =\frac{1}{144}\sum_{t=1}^{144}p_t
    \end{equation}
    
    \begin{equation}
        \widehat p_{d,t}
        =\max\left[
        p_t
        +\widehat y_d
        -\overline p,
        0
        \right]
    \end{equation}
    
    式中$p_t$为附件1的时段价格，该方法的逐时段MAE为0.0939元/kWh，RMSE为0.1207元/kWh，逐时段$R^2=0.8709$。这种方法综合考虑了附件1经验电价的数值和近期电价的波动因素，经$R^2$检验说明拟合程度较好，可以作为预测电价依据。图~\ref{fig:q4_price_consistency}以预测电价为横轴、实际电价为纵轴，展示了全天各时段电价预测值同实际值的对应关系，并用颜色表示样本密度。散点主要沿对角线分布，说明所采用的滚动电价预测模型能够较好地跟踪动态电价的日内变化。

    \subsubsection{问题4-2的日前购电模型}
    
    问题4-2沿用问题2的负载和光伏预测以及80\%分位数风险修正，使用预测电价建立日计划购电与储能MILP。计划购电费按预测电价计算，紧急购电费按实际动态电价计算：
    \begin{equation}
        C_{4\text{-}2}^{\mathrm{plan}}
        =\sum_{d\in\mathcal D}\sum_{t=1}^{T}
        \widehat p_{d,t}g_{d,t},
    \end{equation}
    
    \begin{equation}
        C_{4\text{-}2}^{\mathrm{em}}
        =\sum_{d\in\mathcal D}\sum_{t=1}^{T}
        5p_{d,t}^{\mathrm{act}}e_{d,t}
    \end{equation}
    
    式中$e_{d,t}$为第$d$天第$t$时段的紧急购电量。\par
    
    \subsubsection{问题4-3的多阶段调整模型}
    
    问题4-3沿用问题3的计算模型。三类购电量为$g_{d,t}^{\mathrm{plan}}$、$g_{d,t}^{\mathrm{adj}}$和$e_{d,t}$。相对参考计划的调高量和调低量分别为
    
    \begin{equation}
        \Delta_{d,t}^{+}
        =\max\left(
        g_{d,t}^{\mathrm{adj}}-g_{d,t}^{\mathrm{ref}},0
        \right),
    \end{equation}
    
    \begin{equation}
        \Delta_{d,t}^{-}
        =\max\left(
        g_{d,t}^{\mathrm{ref}}-g_{d,t}^{\mathrm{adj}},0
        \right)
    \end{equation}
    
    调整费用为
    
    \begin{equation}
        C_{4\text{-}3}^{\mathrm{adj}}
        =\sum_{d\in\mathcal D}\sum_{t=1}^{T}
        \left[
        1.5\widehat p_{d,t}\Delta_{d,t}^{+}
        +0.5\widehat p_{d,t}\Delta_{d,t}^{-}
        \right]
    \end{equation}
    
    实际运行使用最终调整购电量，紧急购电量仍按实际负载、光伏和电池放电后的缺口计算：
    
    \begin{equation}
        e_{d,t}
        =\max\left[
        0,\ 
        L_{d,t}^{\mathrm{act}}\Delta t
        -V_{d,t}^{\mathrm{act}}\Delta t
        -g_{d,t}^{\mathrm{adj}}
        -d_{d,t}
        \right]
    \end{equation}
    
    其中$e_{d,t}$为第$d$天第$t$时段的紧急购电量，$L_{d,t}^{\mathrm{act}}$和$V_{d,t}^{\mathrm{act}}$分别为实际用电负荷与实际光伏出力，$d_{d,t}$为电池放电量，$\Delta t$为时段长度。因此，问题4-3的总费用为
    
    \begin{equation}
        C_{4\text{-}3}
        =C_{4\text{-}3}^{\mathrm{plan}}
        +C_{4\text{-}3}^{\mathrm{adj}}
        +C_{4\text{-}3}^{\mathrm{em}}
    \end{equation}
    
    其中计划和调整费用采用预测电价，紧急购电费用采用实际动态电价。储能状态在两个子问题中均满足$S_{d+1,0}=S_{d,T}$。\par

    \section{模型评估与灵敏度分析}
    
    本文接下来将从正确性，有效性，鲁棒性，可解释性和可推广性五个方面对问题一到问题四的模型进行系统性评估。在指标层面，我们分别采用约束类指标，经济类指标和运行类指标这三类指标评价。本文采用约束校验，多问题对比与灵敏度扫描的方法来展开。约束校验用于验证模型的正确性，多问题对比用于观察多个阶段调整和电价波动带来的影响，灵敏度扫描用于判断结论和系统的鲁棒性。下面按此顺序展开。
    
    \subsection{有效性和正确性评估}
    
    正确性是所有评估的前提。本文对问题一至问题四所有的逐时段MILP模型进行了四类校验，以验证模型满足所有的约束条件。\par
    
    第一，功率平衡约束。对每个时段 $t$，检查购电量、放电量、光伏电量之和与充电量、缺电量、负载电量之和是否相等。图~\ref{fig:Residual_curve}直观的展示了系统负载与电量供给功率的残差曲线，经过计算验证，四个问题的所有时段功率平衡偏差均在 $10^{-6}$ kWh量级以内，说明约束严格满足。\par
    
    \begin{figure}[htbp]
        \centering
        \includegraphics[width=0.6\textwidth]{visualization/Chapter6/Residual_curve_of_load_and_supply.pdf}
        \caption{系统负载与电量供给功率残差曲线}
        \label{fig:Residual_curve}
    \end{figure}
    
    第二是储能递推约束。对每个时段检查
    
    \begin{equation}
        \begin{aligned}
            S_{d,t}^{\mathrm{act}} - S_{d,t-1}^{\mathrm{act}} - 0.9c_{d,t} + \frac{d_{d,t}}{0.9} = 0
        \end{aligned}
    \end{equation}
    
    结果显示储能轨迹连续变化无跳跃。第三是储电量范围约束。四个问题中储能设备的储电量始终保持在\([1200,10800]\ \mathrm{kWh}\)之间，未出现越限。
    问题一和问题二强制日初日末储电量相同，问题三和问题四通过跨日传递实现储能连续，均满足题目要求。第四，大型储能设备通常都须满足充放电互斥约束，通过引入二进制变量 \(z_{t}\)，保证了互斥约束的有效性。\par

    上述校验说明，四个问题的MILP模型在数学上自洽，求解结果在物理上可行，模型正确性等到了有效验证。\par
    
    
    有效性关注模型是否真正达到了“保证供电、降低费用”的目标。下面我们分别从购电费用，紧急购电量和弃电量三个角度来进行评估。\par
    
    问题一在固定电价和固定负载下，计划购电费即为总费用，储能通过低充高放降低购电成本。问题二在固定电价下引入紧急购电，总费用由计划购电费和紧急购电费组成。问题三引入多阶段滚动调整后，总费用由计划购电费、调整费和紧急购电费三部分组成。问题四在波动电价下重算问题二和问题三，总费用进一步上升，主要来自电价本身的波动。\par
    
    从数值看，问题三相对问题二，全年紧急购电量从126347.963398 kWh降低到12508.001601 kWh，降幅约90.1\%，说明多阶段调整在降低高价紧急购电方面非常有效。与此同时，调整后购电量高于原计划量，调整费用和计划购电费之和略有增加，总费用比问题二增加约 72060.73 元。这说明多阶段调整并非“无成本地降低紧急购电”，而是用调整费用换取了紧急购电费用的下降。当紧急电价倍数为5倍时，这种交换在紧急购电量降幅极大时是划算的，但总费用的净变化取决于调整价格参数和预报精度。\par
    
    紧急购电量是衡量供电可靠性的关键指标。问题二紧急购电量最高，说明仅靠 0:00 一次计划难以应对光伏和负载的实际波动。问题三通过 6:00、12:00、18:00 三次调整，将紧急购电量压缩到问题二的约 10\%，说明滚动调整能够显著提高计划对实际光伏变化的适应能力。问题四在波动电价下，紧急购电量介于问题二和问题三之间，取决于电价预测精度和风险裕度设置。\par
    
    进一步分析紧急购电的时间分布可以发现，紧急购电主要集中在光伏出力低于预期或负载高于预期的时段，尤其是傍晚光伏快速下降的时段。这与工程直觉一致：当光伏预报偏高而实际光伏偏低时，计划购电量不足以覆盖负载，只能通过紧急购电弥补。多阶段调整的价值正在于在白天就能发现这种偏差并提前修正。\par
    
    弃电量衡量的是计划购电量偏高的代价。问题一和问题二弃电量较低，因为计划购电量贴近预测净负荷。问题三和问题四弃电量明显上升，原因是风险裕度使计划购电量偏高，部分富余电量无法被储能完全吸收。弃电量的增加是降低紧急购电风险的代价，二者之间存在明显的权衡关系。从数值看，问题三最优裕度下弃电量约为 2.0 GWh，而紧急购电量仅约 4.78 万 kWh。这说明模型更倾向于“多买一点、弃掉一点”，而不是“少买一点、紧急购电”。这种倾向在紧急电价为 5 倍时是合理的，因为紧急购电的单位成本远高于弃电的机会成本。\par
    
    \subsection{模型鲁棒性和稳健性评估}
    
    稳健性关注结论是否依赖某一组特定参数，鲁棒性讨论在预测误差、电价波动以及极端场景等不利条件下模型的性能表现。本文重点对问题三和问题四的风险裕度、紧急电价倍数、调整电价系数、预测误差和储能参数进行灵敏度分析。\par
    
    风险裕度是问题三和问题四中最关键的参数。本文将风险裕度分为两段：0:00–6:00 的夜间分位和 6:00–24:00 的白天分位。通过粗扫、细扫和一维切片，共评估 67 个配置，每个配置对应一次完整的365天滚动仿真。粗扫结果显示，沿白天分位总费用呈现明显的U形。白天分位过低时，计划购电量不足，紧急购电费用高；白天分位过高时，计划购电量偏高，弃电量增加，计划购电费用上升。U 形的最低点出现在白天分位 0.55–0.60 之间。沿夜间分位总费用变化平缓，原因是夜间仅占 $36/144 = 25\%$ 的时段，且夜间没有调整窗口，裕度变化对总费用的影响被白天稀释。\par
    
    图~\ref{fig:q3_margin_cost}右上给出了固定一个风险裕度分位后，总费用随另一个风险裕度分位变化的曲线；图~\ref{fig:q3_margin_cost}左上给出两个风险裕度分位同时变化时全年总费用的二维分布。两组结果均表明，最优裕度附近存在一个范围较宽的低费用区域，其中热力图的最优点为\((0.600,0.600)\)，对应最低总费用约为1355.78万元。\par

    从鲁棒性角度看，四个决策时刻已经覆盖了光伏出力变化的主要阶段：0:00 确定全天计划，6:00 修正白天光伏预期，12:00 修正午后光伏预期，18:00 修正夜间安排。即使光伏预报存在误差，四次调整也能在不同阶段逐步修正，而不是把所有风险压在一次计划上。因此，在当前数据条件下，0:00、6:00、12:00、18:00 四个决策时刻已经足够，不需要引入其他时刻的预报。\par
    
    综合以上多个方面，可以得到以下结论。风险裕度是最关键的稳健性参数，但最优裕度是一个平坦区，参数小扰动不会改变结论。紧急电价倍数和调整电价系数会影响最优裕度的位置，但不改变平坦区性质，模型对价格规则变化具有鲁棒性。储能容量和功率是影响费用的主要参数，初始储电量影响较小，模型对储能参数具有一定稳健性。在光伏近零、负载偏高、电价高位、储能容量减半四类极端场景下，模型均能给出可行策略，说明模型具有较好的鲁棒性。上述结论说明，本文模型不仅在正常场景下有效，在参数扰动和不利场景下也能保持稳定，具有工程可用性和推广价值。\par
    
    \subsection{模型可解释性和可推广性评估}
    
    在这四个问题中，储能运行均呈现低充高放特征。储能设备在电价较低的时段充电，在电价较高的时段放电，符合峰谷套利逻辑。这说明 MILP 模型不仅数值上最优，而且运行策略在工程上可解释。调整主要发生在 6:00 和 12:00。6:00 是光伏开始爬坡的时刻，12:00 是光伏发电出力最高的时刻，这两个时刻的预报更新对剩余时段影响最大。18:00 的调整主要影响夜间时段，幅度相对较小。这与光伏出力的日变化规律一致。紧急购电集中在光伏低于预期或负载高于预期的时段。这说明模型能够识别供需缺口，并在实际运行中通过紧急购电弥补。\par
    
    问题三和问题四覆盖 2025 年 2 月至 12 月，跨越春、夏、秋、冬四个季节，光伏出力和负载特征差异明显。模型在各季节均能给出可行策略，说明模型对季节变化具有适应能力。问题一至问题三使用固定分时电价，问题四使用波动电价。模型在两种电价规则下均能求解，说明模型不依赖特定电价结构。灵敏度分析显示，储能容量、功率、效率和初始储电量变化时，模型仍能给出合理策略。\par
    
    也就是说，模型能够很好地适应不同季节，不同电价结构，不同储能参数的使用场景，\par
    
    \subsection{模型改进方向}
    
    模型包含功率平衡、储能递推、充放电互斥、储电量范围和日初日末储能一致等约束，符合微网运行规律。问题三和问题四在 0:00、6:00、12:00、18:00 四个时刻滚动优化，能够利用最新光伏预报和已发生实际负载，显著降低紧急购电风险。在问题三和问题四中，通过风险裕度搜索，模型找到了费用最低的裕度配置，并证明最优裕度是一个平坦区，工程上易于实施。模型约束完整，物理意义非常明确，多阶段滚动能够很好地适应预测更新。灵敏度分析证明模型得出的结论稳健，工程可用度高。\par
    
    不可避免的是，模型预测存在误差，尤其是光伏发电功率日内波动较大时。光伏和负载预测误差会直接影响计划购电量和紧急购电量，模型只能通过风险裕度部分抵消。另外，0:00 计划时无法预知未来光伏和负载的实际值，滚动调整只能在一定程度上弥补和减小误差。\par
    
    模型将期末储电量目标设为固定值，未考虑季节性差异和电池性能带来的耗损，可能造成部分时段储能利用不充分。同时风险裕度由过去 60 天残差的分位数给出，在样本量有限时可能不够稳健。\par
    
    未来可以考虑引入更精细的光伏预测模型，或者使用机器学习方法对光伏发电功率和负载进行联合预测，以进一步做出更优的计算购电策略。此外，模型假设储能设备充放电效率固定，未来可以考虑引入温度、SOC 等因素对效率的影响，使模型更贴近实际运行情况。\par
    
    本章从正确性和有效性、稳健性和鲁棒性、可解释性和可推广性等维度对问题一至问题四的模型进行了系统评估。结果表明，模型约束完整、结果合理、储能运行符合低充高放特征，多阶段滚动调整能够显著降低紧急购电风险。灵敏度分析显示，风险裕度最优是一个平坦区，夜间 0.60、白天 0.60 为最优点，总费用为 1355.78 万元；紧急电价倍数、调整电价系数、预测误差和储能参数扰动下，模型结论保持稳健。当前四个决策时刻已经足够，不需要引入其他时刻的预报。模型的主要局限在于预测误差和两阶段决策的固有局限，未来可通过随机优化和季节性自适应期末 SOC 目标进一步改进。\par
    
    \section{结果分析}
    
    \subsection{综合结论}
    
    在问题一中，储能设备在夜间低电价时段集中充电，在电价较高或负载较大的时段放电，减少了高价时段的外网购电量。所有供需平衡、储电量递推、功率约束和充放电互斥残差均小于$10^{-5}$，全天任意时间段输入与输出都达到了动态平衡。问题一结果为后续问题提供了统一的储能调度基准。\par
    
    问题二中负载和光伏预测能够较好地跟踪实际数据，负载预测的$R^2$为0.97，光伏预测的$R^2$为0.99，白天光伏预测的$R^2$为0.97。预测误差主要出现在光伏日内波动较大的时段，说明天气变化仍是预测误差的重要来源。采用最近60天误差的80\%分位数进行修正后，计划购电量略高于预测均值，有效控制了五倍电价下的缺电风险。\par
    
    问题三进行多阶段调整。通过67组风险裕度搜索，得到夜间和白天的最优分位数。与问题二相比，总费用明显下降，说明及时利用新光伏预报能够降低高价紧急购电风险。\par
    
    问题四使用Rolling方法预测动态电价，并以日内峰谷数据进行修正。预测电价的逐时段$R^2$为0.87、MAE为0.09元/kWh、RMSE为0.12元/kWh，说明该方法能够较好地刻画日内电价变化。\par
    
    四个问题的结果表明：确定性MILP能够给出问题一的全天最优储能调度；滚动时间序列预测和分位数风险修正能够在不确定环境下兼顾购电成本与缺电风险；附件3预报驱动的多阶段调整可以显著降低紧急购电量；动态电价下的4-3模型通过日内信息更新获得了明显优于4-2的经济效果。总体上，本文形成了从确定性优化、滚动预测、风险修正到多阶段动态调度的完整微网购电与储能决策框架。\par
    
    \subsection{应用推广}
    
    在工程应用中，该框架可根据实际数据条件灵活调整。对于仅具备目前电价和负载预测的系统，可采用问题二模型；对于具备日内光伏预报的系统，可采用问题三的多阶段调整模型；对于电价实时波动的市场环境，可采用问题四的波动电价模型。模型参数如风险裕度、紧急电价倍数、调整电价系数等均可根据实际规则重新标定，具有较强的适应性。\par
    
    本文提出的风险裕度平坦区结论具有直接的管理意义：运维人员无需对参数进行精细调优，只要将裕度设置在合理区间内即可获得接近最优的费用表现，降低了实际部署的调参成本。灵敏度分析也表明，模型在预测误差、电价波动和储能参数扰动下仍能给出可行策略，具备较好的鲁棒性。\par
    
    未来，该框架可进一步扩展至多微网协同、需求响应、碳交易等场景，为新型电力系统下的分布式能源消纳与用能成本优化提供参考。\par

        def time_minutes(value) -> int:
        """兼容附件混用的 Excel 时间、字符串和 0:00+1。"""
        if isinstance(value, datetime):
        value = value.time()
        if isinstance(value, time):
        if value.second or value.microsecond:
        raise ValueError(f"时间包含非零秒：{value}")
        return value.hour * 60 + value.minute
        if isinstance(value, (float, int)):
        minutes = float(value) * 1440
        if not np.isfinite(minutes) or abs(minutes - round(minutes)) > 1e-6:
        raise ValueError(f"无法识别 Excel 时间：{value}")
        return round(minutes)
        text = str(value).strip()
        next_day = text.endswith("+1")
        if next_day:
        text = text[:-2]
        parts = text.split(":")
        if len(parts) not in (2, 3) or (len(parts) == 3 and int(parts[2]) != 0):
        raise ValueError(f"无法识别时间：{value}")
        hour, minute = map(int, parts[:2])
        if not 0 <= minute < 60 or not 0 <= hour <= 24 or (hour == 24 and minute):
        raise ValueError(f"时间超出范围：{value}")
        return hour * 60 + minute + 1440 * next_day

        def build_model(data: Inputs, battery: Battery = Battery()) -> Model:
        """变量顺序：[g(144), c(144), d(144), S(145), z(144)]。
        
        状态 S 含日初；其他变量按时段排列。所有充放电变量单位为 kWh。
        """
        t_count = data.periods
        for values in (data.price, data.load_kw, data.pv_kw):
        if np.shape(values) != (t_count,) or not np.isfinite(values).all():
        raise ValueError("输入向量必须等长且为有限数值")
        if np.any(values < 0):
        raise ValueError("第一问输入应非负")
        if t_count < 1:
        raise ValueError("至少需要一个时段")
        if not all(np.isfinite(v) for v in asdict(battery).values()):
        raise ValueError("电池参数必须为有限数值")
        if not (0 < battery.eta_c <= 1 and 0 < battery.eta_d <= 1):
        raise ValueError("效率应在 (0, 1] 内")
        if not (0 <= battery.minimum <= battery.initial <= battery.maximum):
        raise ValueError("初始储电量必须处于运行范围内")
        if battery.dt <= 0 or min(battery.charge_kw, battery.discharge_kw) < 0:
        raise ValueError("时段长度须为正，充放电功率上限须非负")
        
        n = t_count
        blocks = {
            "g": slice(0, n), "c": slice(n, 2 * n), "d": slice(2 * n, 3 * n),
            "S": slice(3 * n, 4 * n + 1), "z": slice(4 * n + 1, 5 * n + 1),
        }
        size = 5 * n + 1
        objective = np.zeros(size)
        objective[blocks["g"]] = data.price  # min sum(p_t * g_t)
        integrality = np.zeros(size, dtype=int)
        integrality[blocks["z"]] = 1
        
        lower = np.zeros(size)
        upper = np.full(size, np.inf)
        c_max = battery.charge_kw * battery.dt
        d_max = battery.discharge_kw * battery.dt
        upper[blocks["c"]] = c_max
        upper[blocks["d"]] = d_max
        lower[blocks["S"]] = battery.minimum
        upper[blocks["S"]] = battery.maximum
        upper[blocks["z"]] = 1
        # S_0 = S_T = 6000，通过相等的上下界固定。
        for position in (blocks["S"].start, blocks["S"].stop - 1):
        lower[position] = upper[position] = battery.initial
        
        matrix = lil_matrix((4 * n, size), dtype=float)
        row_lower = np.full(4 * n, -np.inf)
        row_upper = np.zeros(4 * n)
        demand = (data.load_kw - data.pv_kw) * battery.dt
        for t in range(n):
        g, c, d, s, z = [blocks[key].start + t for key in ("g", "c", "d", "S", "z")]
        # g_t - c_t + d_t = (L_t - PV_t) * dt；光伏全部消纳。
        matrix[t, g], matrix[t, c], matrix[t, d] = 1, -1, 1
        row_lower[t] = row_upper[t] = demand[t]
        # S_{t+1} - S_t - eta_c*c_t + d_t/eta_d = 0。
        row = n + t
        matrix[row, s + 1], matrix[row, s] = 1, -1
        matrix[row, c], matrix[row, d] = -battery.eta_c, 1 / battery.eta_d
        row_lower[row] = row_upper[row] = 0
        # c_t <= C_max*z_t；d_t <= D_max*(1-z_t)。
        matrix[2 * n + t, c], matrix[2 * n + t, z] = 1, -c_max
        matrix[3 * n + t, d], matrix[3 * n + t, z] = 1, d_max
        row_upper[3 * n + t] = d_max
        
        return Model(objective, integrality, Bounds(lower, upper),
        LinearConstraint(matrix.tocsc(), row_lower, row_upper), blocks)
        
        
        def solve_model(model: Model, *, time_limit: float = 60.0,
        relative_gap: float = 0.0, relax: bool = False,
        fixed_z: np.ndarray | None = None):
        """精确 MILP；relax=True 仅用于 LP 下界诊断。
        
        fixed_z 给定完整 0/1 模式后，剩余问题是 LP。这是未来 GA+LP 的内层接口。
        该接口不使用罚函数，不自动放宽日末条件，也不修补不可行模式。
        """
        if time_limit <= 0 or relative_gap < 0:
        raise ValueError("求解时间须为正，最优性间隙须非负")
        lower, upper = model.bounds.lb.copy(), model.bounds.ub.copy()
        integer = model.integrality.copy()
        if relax:
        integer[:] = 0
        if fixed_z is not None:
        mode = np.asarray(fixed_z, dtype=float)
        block = model.blocks["z"]
        if mode.shape != (block.stop - block.start,) or not np.isin(mode, [0, 1]).all():
        raise ValueError("fixed_z 必须为与时段数相同的 0/1 向量")
        lower[block] = upper[block] = mode
        integer[:] = 0
        start = perf_counter()
        result = milp(model.objective, integrality=integer,
        bounds=Bounds(lower, upper), constraints=model.constraints,
        options={"time_limit": time_limit, "mip_rel_gap": relative_gap})
        return result, perf_counter() - start
        
        
        def validate_solution(data: Inputs, battery: Battery, model: Model,
        x: np.ndarray, tolerance: float = 1e-5) -> dict:
        """独立用物理关系核验解，不仅检查求解器的成功标志。"""
        if x is None or not np.isfinite(x).all():
        raise ValueError("没有有限的可行解")
        g, c, d, state, mode = [x[model.blocks[key]] for key in ("g", "c", "d", "S", "z")]
        load, pv = data.load_kw * battery.dt, data.pv_kw * battery.dt
        errors = {
            "balance_kwh": float(np.max(np.abs(g + pv + d - load - c))),
            "storage_transition_kwh": float(np.max(np.abs(
            np.diff(state) - battery.eta_c * c + d / battery.eta_d))),
            "storage_bounds_kwh": max(0.0, float(battery.minimum - state.min()),
            float(state.max() - battery.maximum)),
            "boundary_kwh": float(max(abs(state[0] - battery.initial), abs(state[-1] - battery.initial))),
            "nonnegative_kwh": max(0.0, float(-min(g.min(), c.min(), d.min()))),
            "charge_limit_kwh": max(0.0, float(np.max(c - battery.charge_kw * battery.dt * mode))),
            "discharge_limit_kwh": max(0.0, float(np.max(d - battery.discharge_kw * battery.dt * (1 - mode)))),
            "mode_bounds": max(0.0, float(-mode.min()), float(mode.max() - 1)),
            "mode_integrality": float(np.max(np.abs(mode - np.rint(mode)))),
            "simultaneous_flow_kwh": float(np.max(np.minimum(c, d))),
            "daily_cycle_kwh": float(abs(d.sum() - battery.eta_c * battery.eta_d * c.sum())),
            "daily_energy_kwh": float(abs(g.sum() - load.sum() + pv.sum()
            - (1 - battery.eta_c * battery.eta_d) * c.sum())),
        }
        failures = {key: value for key, value in errors.items() if value > tolerance}
        if failures:
        raise ValueError(f"解未通过可行性检查：{failures}")
        return {"passed": True, "absolute_tolerance": tolerance, "residuals": errors}
        
        
        def clock_label(minutes: int) -> str:
        return f"{minutes // 60:02d}:{minutes % 60:02d}"
        
        
        def result_clock(minutes: int) -> str:
        """把绝对分钟数格式化为 result1 模板使用的时间标签。"""
        day, minute_of_day = divmod(minutes, 24 * 60)
        hour, minute = divmod(minute_of_day, 60)
        suffix = "+1" if day else ""
        return f"{hour}:{minute:02d}{suffix}"
        
        
        def normalize_interval(label: str) -> str:
        """统一模板和内部区间的格式，例如 00:00-04:00 -> 0:00-4:00。"""
        try:
        start, end = str(label).strip().split("-", maxsplit=1)
        start_minutes = time_minutes(start)
        end_minutes = time_minutes(end)
        except (TypeError, ValueError) as exc:
        raise ValueError(f"无法识别时间段：{label!r}") from exc
        return f"{result_clock(start_minutes)}-{result_clock(end_minutes)}"

        def regression_metrics(actual: np.ndarray, prediction: np.ndarray) -> dict:
        """计算 R2、MAE 和 RMSE。"""
        actual_flat = np.asarray(actual, dtype=float).reshape(-1)
        prediction_flat = np.asarray(prediction, dtype=float).reshape(-1)
        if actual_flat.shape != prediction_flat.shape:
        raise ValueError("实际值和预测值形状不一致")
        if not np.isfinite(actual_flat).all() or not np.isfinite(prediction_flat).all():
        raise ValueError("评估数据中存在缺失或非有限值")
        
        error = actual_flat - prediction_flat
        residual_sum = float(np.sum(error**2))
        total_sum = float(np.sum((actual_flat - actual_flat.mean()) ** 2))
        r2 = 1.0 - residual_sum / total_sum if total_sum > 0 else float("nan")
        return {
            "R2": float(r2),
            "MAE": float(np.mean(np.abs(error))),
            "RMSE": float(np.sqrt(np.mean(error**2))),
        }

        ridge_only = np.isfinite(pv_ridge) & ~np.isfinite(pv_prediction)
        pv_prediction[ridge_only] = pv_ridge[ridge_only]
        
        return (
        load_dates,
        fill_initial_missing(load_prediction, "1 月负载预测"),
        fill_initial_missing(pv_prediction, "1 月光伏预测"),
        )

        day, minute_of_day = divmod(minutes, 24 * 60)

        return f"{hour}:{minute:02d}{suffix}"
        
        return f"{clock(start)}-{clock(end)}"
        
        
        def solve_plan_day(
        net_plan_kwh: np.ndarray,
        price: np.ndarray,
        storage_initial: float,
        ) -> DailyPlan:
        """固定计划净负荷下的日 MILP，保证日初日末储电量相同。"""
        n = PERIODS_PER_DAY
        blocks = {
            "g": slice(0, n),
            "c": slice(n, 2 * n),
            "d": slice(2 * n, 3 * n),
            "S": slice(3 * n, 4 * n + 1),
            "r": slice(4 * n + 1, 5 * n + 1),
            "z": slice(5 * n + 1, 6 * n + 1),
        }
        size = 6 * n + 1
        
        objective = np.zeros(size)
        objective[blocks["g"]] = price
        integrality = np.zeros(size, dtype=int)
        integrality[blocks["z"]] = 1
        
        lower = np.zeros(size)
        upper = np.full(size, np.inf)
        upper[blocks["c"]] = POWER_LIMIT
        upper[blocks["d"]] = POWER_LIMIT
        upper[blocks["z"]] = 1
        lower[blocks["S"]] = SOC_MIN
        upper[blocks["S"]] = SOC_MAX
        lower[blocks["S"].start] = upper[blocks["S"].start] = storage_initial
        lower[blocks["S"].stop - 1] = upper[blocks["S"].stop - 1] = storage_initial
        
        matrix = lil_matrix((4 * n, size), dtype=float)
        row_lower = np.full(4 * n, -np.inf)
        row_upper = np.zeros(4 * n)
        for t in range(n):
        g = blocks["g"].start + t
        c = blocks["c"].start + t
        d = blocks["d"].start + t
        s = blocks["S"].start + t
        r = blocks["r"].start + t
        z = blocks["z"].start + t
        
        # g_t + d_t - c_t - spill_t = net_plan_t
        matrix[t, g], matrix[t, d] = 1, 1
        matrix[t, c], matrix[t, r] = -1, -1
        row_lower[t] = row_upper[t] = net_plan_kwh[t]
        
        row = n + t
        matrix[row, s + 1], matrix[row, s] = 1, -1
        matrix[row, c], matrix[row, d] = -ETA_C, 1 / ETA_D
        row_lower[row] = row_upper[row] = 0
        
        matrix[2 * n + t, c], matrix[2 * n + t, z] = 1, -POWER_LIMIT
        matrix[3 * n + t, d], matrix[3 * n + t, z] = 1, POWER_LIMIT
        row_upper[3 * n + t] = POWER_LIMIT
        
        result = milp(
        objective,
        integrality=integrality,
        bounds=Bounds(lower, upper),
        constraints=LinearConstraint(matrix.tocsc(), row_lower, row_upper),
        options={"mip_rel_gap": 0.0},
        )
        if result.x is None or result.status != 0:
        raise RuntimeError(f"第二问单日 MILP 求解失败：{result.message}")
        
        return DailyPlan(
        purchase_kwh=result.x[blocks["g"]],
        charge_kwh=result.x[blocks["c"]],
        discharge_kwh=result.x[blocks["d"]],
        storage_end_kwh=result.x[blocks["S"]][1:],
        )
        
        
        def simulate_actual_day(
        planned_purchase: np.ndarray,
        actual_load_kw: np.ndarray,
        actual_pv_kw: np.ndarray,
        storage_initial: float,
        ) -> ActualResult:
        """按实际供需执行电池：富余优先充电，缺电优先放电。"""
        charge = np.zeros(PERIODS_PER_DAY)
        discharge = np.zeros(PERIODS_PER_DAY)
        emergency = np.zeros(PERIODS_PER_DAY)
        spill = np.zeros(PERIODS_PER_DAY)
        storage_end = np.zeros(PERIODS_PER_DAY)
        storage = storage_initial
        
        for t in range(PERIODS_PER_DAY):
        load = actual_load_kw[t] * DT
        pv = actual_pv_kw[t] * DT
        balance = planned_purchase[t] + pv - load
        
        if balance >= 0:
        charge[t] = min(
        balance,
        POWER_LIMIT,
        (SOC_MAX - storage) / ETA_C,
        )
        spill[t] = max(0.0, balance - charge[t])
        else:
        max_discharge = min(
        -balance,
        POWER_LIMIT,
        ETA_D * (storage - SOC_MIN),
        )
        discharge[t] = max(0.0, max_discharge)
        emergency[t] = max(0.0, -balance - discharge[t])
        
        storage += ETA_C * charge[t] - discharge[t] / ETA_D
        storage = min(SOC_MAX, max(SOC_MIN, storage))
        storage_end[t] = storage
        
        runs: list[tuple[str, float]] = []
        active = np.flatnonzero(emergency > 1e-6)
        if len(active):
        start = previous = int(active[0])
        for value in active[1:]:
        period = int(value)
        if period != previous + 1:
        runs.append(
        (
        f"{interval_label(start).split('-')[0]}-"
        f"{interval_label(previous).split('-')[1]}",
        float(emergency[start:previous + 1].sum()),
        )
        )
        start = period
        previous = period
        runs.append(
        (
        f"{interval_label(start).split('-')[0]}-"
        f"{interval_label(previous).split('-')[1]}",
        float(emergency[start:previous + 1].sum()),
        )
        )
        
        return ActualResult(
        storage_initial_kwh=float(storage_initial),
        charge_kwh=charge,
        discharge_kwh=discharge,
        emergency_kwh=emergency,
        spill_kwh=spill,
        storage_end_kwh=storage_end,
        emergency_runs=runs,
        )

        class PvForecastCorrector:

        for hour in range(24):
        offset = hour - tau
        if not 0 <= offset < 24:
        continue
        xs, ys = [], []
        for day in days:
        values = self.forecasts.get((day, tau))
        if values is None:
        continue
        xs.append(float(values[offset]))
        ys.append(float(self.actual[day][6 * hour:6 * hour + 6].mean()))
        if len(xs) < self.min_pairs:
        continue
        x = np.asarray(xs, dtype=float)
        if x.std() < 1e-6:
        continue
        slope, intercept = np.polyfit(x, np.asarray(ys, dtype=float), 1)
        if slope < 0.0:
        slope, intercept = 1.0, 0.0
        self.regression[(tau, hour)] = (
        float(intercept),
        float(slope),
        float(x.mean()),
        )
        
        def expand(self, values: np.ndarray, decision_hour: int, target: date) -> np.ndarray:
        """把附件 3 的 24 个整点值订正并展开成当天 144 个 10 分钟值。"""
        result = np.zeros(PERIODS_PER_DAY)
        start = decision_hour * 6
        for offset, value in enumerate(values):
        lo = start + 6 * offset
        if lo >= PERIODS_PER_DAY:
        break
        hi = min(lo + 6, PERIODS_PER_DAY)
        hour = (decision_hour + offset) % 24
        level = float(value)
        if self.use_level:
        coef = self.regression.get((decision_hour, hour))
        if coef is not None:
        intercept, slope, mean_forecast = coef
        if mean_forecast > 0 and level >= PV_NIGHT_RATIO * mean_forecast:
        level = max(0.0, intercept + slope * level)
        shape = self.shape.get(hour) if self.use_shape else None
        if shape is None:
        result[lo:hi] = level
        else:
        result[lo:hi] = level * shape[:hi - lo]
        return np.maximum(result, 0.0)
        
        
        def solve_interval_milp(
        net_demand_kwh: np.ndarray,
        price: np.ndarray,
        storage_initial: float,
        *,
        reference_purchase: np.ndarray | None = None,
        ) -> IntervalPlan:
        """求解计划或调整阶段的储能 MILP。"""
        n = len(net_demand_kwh)
        adjustment = reference_purchase is not None
        adjustment_blocks = {}
        if adjustment:
        adjustment_blocks = {
            "up": slice(7 * n + 1, 8 * n + 1),
            "down": slice(8 * n + 1, 9 * n + 1),
        }
        blocks = {
            "g": slice(0, n),
            "c": slice(n, 2 * n),
            "d": slice(2 * n, 3 * n),
            "S": slice(3 * n, 4 * n + 1),
            "u": slice(4 * n + 1, 5 * n + 1),
            "z": slice(5 * n + 1, 6 * n + 1),
            "short": slice(6 * n + 1, 7 * n + 1),
        }
        blocks.update(adjustment_blocks)
        size = 9 * n + 1 if adjustment else 7 * n + 1
        
        objective = np.zeros(size)
        if adjustment:
        objective[blocks["up"]] = 1.5 * price
        objective[blocks["down"]] = 0.5 * price
        else:
        objective[blocks["g"]] = price
        terminal_penalty = 5.0 * float(np.mean(price))
        objective[blocks["short"]] = terminal_penalty
        
        integrality = np.zeros(size, dtype=int)
        integrality[blocks["z"]] = 1
        
        lower = np.zeros(size)
        upper = np.full(size, np.inf)
        upper[blocks["c"]] = POWER_LIMIT
        upper[blocks["d"]] = POWER_LIMIT
        upper[blocks["z"]] = 1
        lower[blocks["S"]] = SOC_MIN
        upper[blocks["S"]] = SOC_MAX
        lower[blocks["S"].start] = upper[blocks["S"].start] = storage_initial
        
        row_count = 5 * n + 1 if adjustment else 4 * n + 1
        matrix = lil_matrix((row_count, size), dtype=float)
        row_lower = np.full(row_count, -np.inf)
        row_upper = np.zeros(row_count)
        
        for t in range(n):
        g = blocks["g"].start + t
        c = blocks["c"].start + t
        d = blocks["d"].start + t
        s = blocks["S"].start + t
        u = blocks["u"].start + t
        z = blocks["z"].start + t
        
        matrix[t, g], matrix[t, d] = 1, 1
        matrix[t, c], matrix[t, u] = -1, -1
        row_lower[t] = row_upper[t] = net_demand_kwh[t]
        
        row = n + t
        matrix[row, s + 1], matrix[row, s] = 1, -1
        matrix[row, c], matrix[row, d] = -ETA_C, 1 / ETA_D
        row_lower[row] = row_upper[row] = 0
        
        matrix[2 * n + t, c], matrix[2 * n + t, z] = 1, -POWER_LIMIT
        matrix[3 * n + t, d], matrix[3 * n + t, z] = 1, POWER_LIMIT
        row_upper[3 * n + t] = POWER_LIMIT
        
        if adjustment:
        up = blocks["up"].start + t
        down = blocks["down"].start + t
        matrix[4 * n + t, g] = 1
        matrix[4 * n + t, up], matrix[4 * n + t, down] = -1, 1
        row_lower[4 * n + t] = row_upper[4 * n + t] = (
        float(reference_purchase[t])
        )
        
        terminal_row = row_count - 1
        matrix[terminal_row, blocks["S"].stop - 1] = 1
        matrix[terminal_row, blocks["short"].start] = 1
        row_lower[terminal_row] = SOC_TARGET
        row_upper[terminal_row] = np.inf
        
        result = milp(
        objective,
        integrality=integrality,
        bounds=Bounds(lower, upper),
        constraints=LinearConstraint(matrix.tocsc(), row_lower, row_upper),
        options={"mip_rel_gap": 0.0},
        )
        if result.x is None or result.status != 0:
        raise RuntimeError(f"第三问区间 MILP 求解失败：{result.message}")
        
        return IntervalPlan(
        purchase_kwh=result.x[blocks["g"]],
        charge_kwh=result.x[blocks["c"]],
        discharge_kwh=result.x[blocks["d"]],
        storage_end_kwh=result.x[blocks["S"]][1:],
        )
        
        
        def simulate_segment(
        purchase_kwh: np.ndarray,
        actual_load_kw: np.ndarray,
        actual_pv_kw: np.ndarray,
        storage_initial: float,
        ) -> tuple[np.ndarray, np.ndarray, np.ndarray, np.ndarray, float]:
        """按实际负载和实际光伏运行一个连续时段区间。"""
        n = len(purchase_kwh)
        charge = np.zeros(n)
        discharge = np.zeros(n)
        emergency = np.zeros(n)
        spill = np.zeros(n)
        storage_end = np.zeros(n)
        storage = float(storage_initial)
        
        for t in range(n):
        balance = (
        purchase_kwh[t]
        + actual_pv_kw[t] * DT
        - actual_load_kw[t] * DT
        )
        if balance >= 0:
        charge[t] = min(
        balance,
        POWER_LIMIT,
        max(0.0, (SOC_MAX - storage) / ETA_C),
        )
        spill[t] = max(0.0, balance - charge[t])
        else:
        discharge[t] = min(
        -balance,
        POWER_LIMIT,
        max(0.0, ETA_D * (storage - SOC_MIN)),
        )
        emergency[t] = max(0.0, -balance - discharge[t])
        storage += ETA_C * charge[t] - discharge[t] / ETA_D
        storage = min(SOC_MAX, max(SOC_MIN, storage))
        storage_end[t] = storage
        
        return charge, discharge, emergency, spill, storage
        
        
        def updated_load_forecast(
        base_load: np.ndarray,
        actual_load: np.ndarray,
        decision_index: int,
        ) -> np.ndarray:
        """利用当天已发生的负载对剩余时段做水平偏差修正。"""
        if decision_index <= 0:
        return base_load.copy()
        observed_error = (
        actual_load[:decision_index] - base_load[:decision_index]
        )
        correction = float(np.mean(observed_error))
        scale = max(float(np.mean(base_load[decision_index:])), 1.0)
        correction = float(np.clip(correction, -0.2 * scale, 0.2 * scale))
        result = base_load.copy()
        result[decision_index:] = np.maximum(
        0.0, base_load[decision_index:] + correction
        )
        return result
        
        
        def solve_day(
        target: date,
        price: np.ndarray,
        base_load: np.ndarray,
        corrector: PvForecastCorrector,
        actual_load: np.ndarray,
        actual_pv: np.ndarray,
        storage_initial: float,
        risk_margin: np.ndarray,
        ) -> DailyResult:
        """完成一天的计划、三次调整和实际运行。"""
        pv0 = corrector.expand(corrector.forecasts[(target, 0)], 0, target)
        forecast_net0 = (base_load - pv0) * DT
        plan_net = forecast_net0 + risk_margin
        plan = solve_interval_milp(plan_net, price, storage_initial)
        
        final_purchase = plan.purchase_kwh.copy()
        actual_charge = np.zeros(PERIODS_PER_DAY)
        actual_discharge = np.zeros(PERIODS_PER_DAY)
        actual_emergency = np.zeros(PERIODS_PER_DAY)
        actual_spill = np.zeros(PERIODS_PER_DAY)
        storage_trace = np.zeros(PERIODS_PER_DAY)
        storage = float(storage_initial)
        cursor = 0
        
        for decision_hour in (6, 12, 18):
        decision_index = decision_hour * 6
        segment_start = storage
        (
        charge_segment,
        discharge_segment,
        emergency_segment,
        spill_segment,
        storage,
        ) = simulate_segment(
        final_purchase[cursor:decision_index],
        actual_load[cursor:decision_index],
        actual_pv[cursor:decision_index],
        storage,
        )
        actual_charge[cursor:decision_index] = charge_segment
        actual_discharge[cursor:decision_index] = discharge_segment
        actual_emergency[cursor:decision_index] = emergency_segment
        actual_spill[cursor:decision_index] = spill_segment
        storage_trace[cursor:decision_index] = (
        segment_start
        + np.cumsum(
        ETA_C * charge_segment - discharge_segment / ETA_D
        )
        )
        cursor = decision_index
        
        updated_load = updated_load_forecast(
        base_load, actual_load, decision_index
        )
        pv_current = corrector.expand(
        corrector.forecasts[(target, decision_hour)], decision_hour, target
        )
        forecast_net = (updated_load - pv_current) * DT
        future_net = (
        forecast_net[decision_index:] + risk_margin[decision_index:]
        )
        adjusted = solve_interval_milp(
        future_net,
        price[decision_index:],
        storage,
        reference_purchase=plan.purchase_kwh[decision_index:],
        )
        final_purchase[decision_index:] = adjusted.purchase_kwh
        
        segment_start = storage
        (
        charge_segment,
        discharge_segment,
        emergency_segment,
        spill_segment,
        storage,
        ) = simulate_segment(
        final_purchase[cursor:],
        actual_load[cursor:],
        actual_pv[cursor:],
        storage,
        )
        actual_charge[cursor:] = charge_segment
        actual_discharge[cursor:] = discharge_segment
        actual_emergency[cursor:] = emergency_segment
        actual_spill[cursor:] = spill_segment
        storage_trace[cursor:] = (
        segment_start
        + np.cumsum(
        ETA_C * charge_segment - discharge_segment / ETA_D
        )
        )
        
        delta = final_purchase - plan.purchase_kwh
        adjustment_cost = float(
        np.sum(
        1.5 * price * np.maximum(delta, 0.0)
        + 0.5 * price * np.maximum(-delta, 0.0)
        )
        )
        
        return DailyResult(
        target_date=target,
        plan_purchase=plan.purchase_kwh,
        adjusted_purchase=final_purchase,
        charge=actual_charge,
        discharge=actual_discharge,
        emergency=actual_emergency,
        spill=actual_spill,
        storage_initial=float(storage_initial),
        storage_end=storage_trace,
        plan_cost=float(price @ plan.purchase_kwh),
        adjustment_cost=adjustment_cost,
        emergency_cost=float(5 * price @ actual_emergency),
        )
        
        
        def merge_emergency_runs(
        emergency: np.ndarray,
        ) -> list[tuple[str, float]]:
        active = np.flatnonzero(emergency > 1e-6)
        runs = []
        if not len(active):
        return runs
        start = previous = int(active[0])
        for value in active[1:]:
        period = int(value)
        if period != previous + 1:
        runs.append(
        (
        f"{interval_label(start).split('-')[0]}-"
        f"{interval_label(previous).split('-')[1]}",
        float(emergency[start:previous + 1].sum()),
        )
        )
        start = period
        previous = period
        runs.append(
        (
        f"{interval_label(start).split('-')[0]}-"
        f"{interval_label(previous).split('-')[1]}",
        float(emergency[start:previous + 1].sum()),
        )
        )
        return runs

        def segmented_risk_margin(
        residuals: np.ndarray,
        quantile_overnight: float,
        quantile_day: float,
        ) -> np.ndarray:
        """按“还有没有调整窗口”分段取残差分位。
        
        0:00-6:00 这 36 个时段在 6:00 之前没有任何调整机会，缺电只能走 5 倍电价，
        因此保留较高分位；6:00 之后的时段至少有 1 次 1.5 倍电价的调整窗口，
        对冲的边际收益低得多，用较低分位，避免“计划买太多、最后弃掉”。
        """
        sample = np.atleast_2d(np.asarray(residuals, dtype=float))
        margin = np.empty(PERIODS_PER_DAY)
        margin[:OVERNIGHT_SLOTS] = np.quantile(
        sample[:, :OVERNIGHT_SLOTS], quantile_overnight, axis=0, method="linear"
        )
        margin[OVERNIGHT_SLOTS:] = np.quantile(
        sample[:, OVERNIGHT_SLOTS:], quantile_day, axis=0, method="linear"
        )
        return margin

        def run_simulation(
        quantile_overnight: float = RISK_QUANTILE_OVERNIGHT,
        quantile_day: float = RISK_QUANTILE_DAY,
        shape_window: int = PV_SHAPE_WINDOW,
        use_correction: bool = True,
        collect_results: bool = False,
        ) -> dict:
        """整年滚动模拟，返回输出区间（OUTPUT_START~OUTPUT_END）的费用汇总。
        
        裕度参数只影响 segmented_risk_margin 的分位取值，其余流程保持主模型口径不变。
        完全一致，因此可以把它当成“给定裕度 → 总费用”的黑箱函数，反复调用。
        """
        inputs = load_inputs()
        price = inputs["price"]
        actual_dates = inputs["actual_dates"]
        actual_load = inputs["actual_load"]
        actual_pv = inputs["actual_pv"]
        load_forecasts = inputs["load_forecasts"]
        pv_forecasts = inputs["pv_forecasts"]
        
        corrector = PvForecastCorrector(
        pv_forecasts,
        window=shape_window,
        use_level=use_correction,
        use_shape=use_correction,
        )
        
        prices_by_date = {target: price for target in actual_dates}
        actual_by_date = {target: index for index, target in enumerate(actual_dates)}
        residual_history: list[np.ndarray] = []
        storage = SOC_INITIAL
        
        days = 0
        total_plan = 0.0
        total_adjusted = 0.0
        total_plan_cost = 0.0
        total_adjustment_cost = 0.0
        total_emergency = 0.0
        total_emergency_cost = 0.0
        total_spill = 0.0
        total_charge = 0.0
        total_discharge = 0.0
        results = []
        
        started = perf_counter()
        for target in actual_dates:
        if target not in load_forecasts:
        raise ValueError(f"{target} 缺少负载预测")
        corrector.fit(target)
        risk_margin = (
        segmented_risk_margin(
        np.asarray(residual_history[-RESIDUAL_WINDOW_DAYS:], dtype=float),
        quantile_overnight,
        quantile_day,
        )
        if residual_history
        else np.zeros(PERIODS_PER_DAY)
        )
        actual_index = actual_by_date[target]
        base_load = load_forecasts[target]
        result = solve_day(
        target,
        prices_by_date[target],
        base_load,
        corrector,
        actual_load[actual_index],
        actual_pv[actual_index],
        storage,
        risk_margin,
        )
        storage = float(result.storage_end[-1])
        
        forecast_pv0 = corrector.expand(pv_forecasts[(target, 0)], 0, target)
        forecast_net0 = (base_load - forecast_pv0) * DT
        actual_net = (
        actual_load[actual_index] - actual_pv[actual_index]
        ) * DT
        residual_history.append(actual_net - forecast_net0)
        corrector.observe(target, actual_pv[actual_index])
        
        if OUTPUT_START <= target <= OUTPUT_END:
        days += 1
        total_plan += float(result.plan_purchase.sum())
        total_adjusted += float(result.adjusted_purchase.sum())
        total_plan_cost += result.plan_cost
        total_adjustment_cost += result.adjustment_cost
        total_emergency += float(result.emergency.sum())
        total_emergency_cost += result.emergency_cost
        total_spill += float(result.spill.sum())
        total_charge += float(result.charge.sum())
        total_discharge += float(result.discharge.sum())
        if collect_results:
        results.append(result)
        
        summary = {
            "days": days,
            "plan_kwh": total_plan,
            "adjusted_kwh": total_adjusted,
            "plan_cost": total_plan_cost,
            "adjustment_cost": total_adjustment_cost,
            "emergency_kwh": total_emergency,
            "emergency_cost": total_emergency_cost,
            "spill_kwh": total_spill,
            "charge_kwh": total_charge,
            "discharge_kwh": total_discharge,
            "total_cost": total_plan_cost + total_adjustment_cost + total_emergency_cost,
            "storage_end": storage,
            "quantile_overnight": float(quantile_overnight),
            "quantile_day": float(quantile_day),
            "shape_window": int(shape_window),
            "use_correction": bool(use_correction),
            "seconds": perf_counter() - started,
        }
        if collect_results:
        summary["results"] = results
        return summary
