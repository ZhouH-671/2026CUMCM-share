# 问题三 · 裕度搜索（question3-4）

模型本体与 `question3-3` 完全一致（历史订正光伏展开 + 分段风险裕度），
本目录只做一件事：**把“风险裕度分位”当作自变量，搜索使总费用最低的取值，并画成曲线/热力图**。

裕度有两个维度：

- `quantile_overnight`：0:00-6:00 共 36 个 10 分钟时段的残差分位（此段没有调整窗口，缺电只能走 5 倍电价）；
- `quantile_day`：6:00-24:00 共 108 个时段的分位（此后有 1~3 次 1.5 倍调整窗口）。

## 1. 搜索方法：先大范围、再缩小

| 阶段 | 范围 | 步长 | 配置数 | 目的 |
| --- | --- | --- | --- | --- |
| A 粗扫 | 夜间 0.50~0.90 × 白天 0.25~0.75 | 0.10 | 30 | 找出费用下降的方向和大致区域 |
| B 细扫 | 粗扫最优点 ±0.05 | 0.025 | 24 | 在最优区域加密，定位最低点 |
| C 切片 | 固定一维、另一维 0.20~0.95 | 0.05 | 13 | 生成一维曲线，供画图与敏感性分析 |

- 共 67 个**互不重复**的配置；相同配置自动跳过，CSV 逐条追加，**中断可直接续跑**。
- 用 8 个进程并行（本机 22 核），总计算量 10,443 CPU·秒 ≈ 2.9 核·小时，**墙钟约 22 分钟**。
- 每个配置都是一次完整的 365 天滚动仿真（前 31 天为预热，统计口径为 2025-02-01~12-31 的 334 天），
  与 `question3-3` 逐日同口径，因此费用可以直接横向比较。

读法：**沿白天分位是一条明显的 U 形**（左端 5 倍紧急电价，右端弃电），最低点在 0.55~0.60；

因为夜间只占 36/144 = 25% 的时段，翻不了盘。

## 4. 结论：最优裕度是一个“平坦区”，而不是一个尖点

- **最优点：夜间 0.60、白天 0.60，总费用 13,557,776.15 元（1355.78 万元）。**
- 平坦区：夜间 ∈ [0.55, 0.70] × 白天 ∈ [0.55, 0.65]，费用都在 1355.8~1357.7 万元之间（差 < 0.15%）。
  工程上取区间中点即可，不敏感 —— 这说明该参数不需要精调到小数点后两位。
- **白天分位是主变量**（U 形，左右两端各贵 3%~11%），**夜间分位是次变量**（0.5~0.7 内几乎无差别）。
  原因是 6:00 之后才有 1.5 倍调整窗口，白天的裕度直接决定“多买→弃电”还是“少买→紧急购电”。
- 权衡的量化（相对最优点）：白天分位降到 0.20 时，计划购电费省 **126.6 万**，
  但调整费多付 **96.6 万**、紧急购电费多付 **188.8 万**，净亏 **158.7 万**；
  升到 0.80 时，计划购电费多花 **73.0 万**，只换回调整费 12.8 万 + 紧急费 20.4 万，净亏 **39.8 万**。

| 完美预见下界 | — | 20.2 | — | 0 | 0.99 | 1224.5 |

- 相对 `question3-2` 省 **66.0 万元（-4.6%）**；相对 `question3-3` 只再省 **0.83 万元（-0.06%）**。
- 也就是说：**`question3-3` 凭经验取的 0.70/0.60 已经落在最优平坦区里**，
  搜索的价值在于证明“这个选择是对的、而且不敏感”，而不是再抠出很多钱。
- 距完美预见下界仍差 **131.3 万元（+10.7%）**，这部分不是裕度能解决的，要靠随机优化/两阶段 recourse，
  以及把期末 SOC 目标做成季节性自适应。

## 7. 用法

    python src/search.py                 # 粗扫 + 细扫 + 切片（约 22 分钟，8 进程）
    python src/search.py --stage coarse  # 只做大范围粗扫（约 8 分钟）
    python src/search.py --dry-run       # 只打印搜索计划，不计算
    python src/search.py --workers 12    # 调整并行度
    python src/plot.py                   # 读 CSV 画三张图 + 生成 best_config.md
    python src/problem.py --quantile-overnight 0.60 --quantile-day 0.60   # 复现最优解并导出 xlsx

搜索是**增量**的：`result/margin_search.csv` 已有的配置会自动跳过，改完范围直接重跑即可续算。

## 8. 还可以继续做的

- 把裕度从“分位数”改成“分位数 + 预报时效衰减”，即 6:00/12:00/18:00 三次调整用逐次变小的裕度。
- 对每个 10 分钟时段分别搜分位（现在是两段常数），但要注意过拟合风险：334 天样本下，
  逐时段分位很容易把噪声当规律，建议用交叉验证而不是全样本最优。
- 把 0.5 / 1.5 / 5 三个电价系数一起纳入敏感性分析，回答“如果违约电价规则变了，最优裕度怎么移动”。
